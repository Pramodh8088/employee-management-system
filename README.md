# Employee Management System

## Description

A Django-based Employee Management System that allows administrators to manage employees and departments.

## Features

- Login & Logout
- Dashboard
- Department CRUD
- Employee CRUD
- Employee Details
- Employee Image Upload
- Search
- Pagination
- Bootstrap Responsive UI

## Technologies Used

- Python
- Django
- MySQL
- HTML
- CSS
- Bootstrap

## Installation

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
